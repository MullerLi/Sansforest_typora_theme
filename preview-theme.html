行距與 Inline 測試 Line Height & Inline Styles

一般段落測試：山霧、街道、筆記、版面、節奏與層級，這些字可以快速看出中文無襯線字體在不同畫面密度下的穩定性。行距已提升至 1.65，讓含有 inline code、粗體、斜體 或數學符號（如 E = mc²、∑ f(x) dx）的行不會因高度不一而被截斷。

第二段落：長文閱讀時，行與行之間是否有足夠的呼吸空間？字句是否清晰可辨？段落之間的分隔是否明確？連結樣式在段落中的視覺協調性也請一併確認。

設計不是把東西排整齊而已，而是讓層級、節奏與閱讀情緒同時成立。
  • 清單項目一：確認 Blix 在列表中是否仍清楚。
  • 清單項目二：檢查列表行高是否自然（line-height: 1.65）。
  • 清單項目三：觀察亮暗主題切換後的對比與背景色分層。
  1. Dark 模式：背景應為深灰 #1C1C1E（非純黑）。
  2. 程式碼字體：應顯示 IBM Plex Mono（inspect 確認 font-family）。
  3. 行距：段落文字行與行之間比舊版更寬鬆。

Code Block — IBM Plex Mono

/* Sansforest Theme — typography constants */
const theme = {
  name: "sansforest",
  bodyFont: "Blix",
  monoFont: "IBM Plex Mono",   // 確認此字體是否正確渲染
  lineHeight: {
    base: 1.6,
    paragraph: 1.65,           // 避免 inline formula 被截斷
  },
  bg: {
    dark: { editor: "#1C1C1E", sidebar: "#111111" },
    light: { editor: "#FAFAFA", sidebar: "#E8E8ED" },
  },
};
