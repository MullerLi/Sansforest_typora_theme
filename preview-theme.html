Heading 6 標題六

一般段落測試：山霧、街道、筆記、版面、節奏與層級，這些字可以快速看出中文無襯線字體在不同畫面密度下的穩定性。

設計不是把東西排整齊而已，而是讓層級、節奏與閱讀情緒同時成立。
  • 清單項目一：確認 `Blix` 在列表中是否仍清楚。
  • 清單項目二：檢查縮排與行高是否自然。
  • 清單項目三：觀察亮暗主題切換後的對比。
  1. 先看 H1 到 H6 的下方距離。
  2. 再看正文中文是否已不是 IBM Plex Sans TC。
  3. 最後確認表格與程式碼是否正常。

Inline Styles

你也可以測試 粗體文字、斜體文字、連結樣式、以及 inline code 的整體協調性。

const preview = {
  theme: "sansforest",
  font: "Blix",
  check: ["heading spacing", "body font", "light/dark"]
};
